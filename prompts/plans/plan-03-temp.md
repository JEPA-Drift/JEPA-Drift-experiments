  1. Résumé                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                      
  Construire le jeu D3 (coupe transversale S&P 500, ~500 titres) : univers depuis CD-DFM/Wikipedia, cours ajustés depuis Yahoo Finance (yfinance), log-rendements, caractéristiques datées (beta_252, vol_63, mom_12_1, rev_21, one-hot GICS) connues à l'ouverture de t, sous-ensembles d3_239 et d3_500 au format D2, chargeur      
  jepadrift/data_loader/sp500.py, tests de contrat, profil descriptif et écarts documentés. Bloquant pour J2 (25 octobre) et J3 (1er novembre).

Règle de repli déterministe pour les 239 titres

  • Règle : prendre les 239 tickers avec le plus grand nombre de jours de trading depuis 2000-01-01 ; ex æquo, ordre alphabétique

Table Wikipedia

  Étape 2 — Cours (item 2 du prompt)                                                                                                                                                                                                                                                                                           [0/101]
                                                                                                                                                                                                                                                                                                                                      
  • Source : yfinance.download(tickers, start='2000-01-01', auto_adjust=True, progress=False)                                                                                                                                                                                                                                         
  • Par ticker (pas de batch — yfinance batch est peu fiable) : yf.Ticker(tk).history(start='2000-01-01', auto_adjust=True)                                                                                                                                                                                                           
  • Cache : data/raw/d3_yf/<TICKER>.parquet — colonnes date, close (ajusté), SHA-256 dans un fichier data/raw/d3_yf/_hashes.json                                                                                                                                                                                                      
  • Reprise : si le cache existe et --refresh absent, skip ; sinon télécharger                                                                                                                                                                                                                                                        
  • Backoff exponentiel : en cas d'échec, attendre 2^n secondes (n = 1, 2, 3, max 60s), 5 tentatives max                                                                                                                                                                                                                              
  • Journaliser chaque échec dans logs/data/d3_build.log (jamais silencieux)                                                                                                                                                                                                                                                          
  • Ticker mapping : dictionnaire explicite {'BRK.B': 'BRK-B', 'BF.B': 'BF-B', ...} (Wikipedia → Yahoo)                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                                      
  Étape 3 — Rendements (item 3 du prompt)                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                      
  • Log-rendements : r[t] = log(close[t] / close[t-1])                                                                                                                                                                                                                                                                                
  • Pas de forward-fill                                                                                                                                                                                                                                                                                                               
  • in_universe[t,i] = vrai ssi close existe en t-1 et en t (donc r[t,i] non-NaN)
